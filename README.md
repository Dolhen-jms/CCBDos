# PI LINAGORA - Groupe 8 : dépôt de travail

Dépôt temporaire de l'équipe, en attendant le GitLab LINAGORA.

## Objectif

Reconstruire le projet depuis zéro, en partant de l'existant :
- le prototype d'Alexandre Pujol : https://github.com/roddhjav/server
- ce qui a été dit et décidé en réunion (comptes rendus).

Le but est de comprendre chaque brique en la remontant nous-mêmes, plutôt que de reprendre
le prototype tel quel.

## Organisation

- Une branche par membre : `baptiste`, `gabriel`, `raphael`.
- Chacun travaille librement sur sa branche : essais, impasses, tentatives, tout est permis.
- `main` reste vide (ou ne contient que ce README) tant qu'on n'a pas mis en commun.
- Plus tard, on compare les approches et on fusionne dans `main` ce qui marche,
  avant de migrer vers le GitLab LINAGORA.

## Règles

- Aucun secret dans le dépôt : clés privées (verity, GPG, SSH), mots de passe, certificats de dev.
- Noter dans les messages de commit ce qui a été tenté et le résultat (même en cas d'échec) :
  ça servira au rapport R&D.
